# Product

## Platform

web

## Product Purpose

Dastarkhan creates seven-day meal plans from a person's kitchen equipment, weekly budget, selected Astana stores, eating style and weight goals. The user requested an interactive kitchen, grocery nutrition data, recipes and a meal guide.

## Capabilities and Constraints

Existing React/Vinext app. Product offers come from an Arzan snapshot and refresh endpoints. Nutrition is estimated from generic foods, not verified branded labels. Store coverage is derived from the dataset and must never be inflated by UI copy. The built-in chat is a rules-based guide; open-ended AI is not connected. Preferences currently last for the session. Recipe variations are not all distinct, professionally authored recipes.

## Brand Commitments

Preserve Dastarkhan, the interactive kitchen asset, Astana focus, tenge pricing and working planning constraints. The user authorized a substantial professional UI redesign and delegated visual decisions.
